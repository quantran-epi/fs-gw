## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-04 | Elevation of Privilege | src/routes/fs.route.js | mitigate | Sanitize all paths using sanitizePath before calling any filesystem methods to block DOS device execution and stream manipulation |
| T-02-05 | Denial of Service | src/routes/fs.route.js | mitigate | Rely on bounded readJsonBody (10MB limit) to reject oversized payloads before buffering into memory |
| T-02-06 | Information Disclosure | src/routes/fs.route.js | mitigate | Standardize error responses to avoid leaking raw Node stack traces to client; return clean { ok: false, error, code } envelopes |
| T-02-SC | Tampering | package dependencies | mitigate | Zero external npm dependencies. Pure Node.js stdlib implementation |
</threat_model>
