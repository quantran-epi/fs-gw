<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Caller → Command Validator | Untrusted command and arguments cross into process execution validation |
| Process Service → OS Process Spawn | Node.js child_process.spawn invokes OS binaries and child tasks |
| Process Service → OS taskkill.exe | OS process management utility terminates process trees by PID |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-01 | Elevation of Privilege | src/utils/command.js | mitigate | Enforce array-only arguments and default shell: false to prevent shell metacharacter injection (&, |, ;) and batch file exploitation (CVE-2024-27980) |
| T-03-02 | Denial of Service | src/services/process.service.js | mitigate | Prevent orphan process accumulation and fork bombs via timeout watchdog and taskkill.exe /pid <PID> /T /F tree termination |
| T-03-03 | Denial of Service | src/services/process.service.js | mitigate | Enforce 10MB maxBuffer on buffered process stdout/stderr accumulation to prevent Node.js heap exhaustion |
| T-03-04 | Denial of Service | src/services/process.service.js | mitigate | Implement stream backpressure in SSE handler (pause stdout when res.write returns false, resume on drain) to prevent memory buildup on high-output CLI tasks |
| T-03-SC | Tampering | package dependencies | mitigate | Zero external npm dependencies. Standard library only (node:child_process, node:crypto, node:path) |
</threat_model>
