<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Client HTTP Request → Route Handlers | Untrusted HTTP requests cross into process execution dispatch |
| HTTP Server → Event Stream (SSE) | Persistent chunked connection transmitting real-time execution telemetry |
| Process Registry → OS Signal / Taskkill | Process termination signals dispatched to host OS |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-05 | Elevation of Privilege | src/routes/exec.route.js | mitigate | Validate all execution requests via validateExecInput before invoking process service; enforce shell: false default |
| T-03-06 | Denial of Service | src/routes/exec.route.js | mitigate | Abort child process tree when client closes SSE HTTP connection before process finishes |
| T-03-07 | Information Disclosure | src/routes/exec.route.js | mitigate | Format errors into standardized { ok: false, error, code } envelopes without exposing sensitive host stack traces |
| T-03-08 | Denial of Service | index.js | mitigate | Hook registry.killAllSync() to process exit and shutdown signals (SIGINT, SIGTERM) to prevent background zombie processes |
| T-03-SC | Tampering | package dependencies | mitigate | Zero external npm dependencies. Standard library only (node:http, node:child_process, node:crypto) |
</threat_model>
