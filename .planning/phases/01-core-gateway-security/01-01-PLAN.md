Purpose: Provide a reliable, secure local communication channel for the desktop application running under Windows 11 Enterprise EDR policies.
Output: Working HTTP server package with automated test suite covering lifecycle, loopback isolation, DNS rebinding guard, and healthcheck.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser / External Network -> Gateway Server | Untrusted web applications and LAN devices attempting to probe port 4820 |
| Local Client -> Gateway HTTP Server | Tauri desktop webview or local developer process communicating over loopback |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-01 | Elevation of Privilege | src/middleware/security.js | mitigate | Validate req.headers.host against strict loopback set (127.0.0.1, localhost). Reject foreign hosts with HTTP 403 Forbidden and ERR_FORBIDDEN_HOST per CORE-04. |
| T-01-02 | Information Disclosure | src/server.js / src/utils/response.js | mitigate | Catch all unhandled exceptions; return standardized JSON error envelope { ok: false, error: string, code: string } without leaking stack traces or internal paths per CORE-05. |
| T-01-03 | Tampering / Repudiation | src/server.js | mitigate | Explicitly bind listener to IPv4 loopback '127.0.0.1'. Never bind '0.0.0.0' or expose on public network interfaces per CORE-01. |
| T-01-SC | Tampering | package.json | mitigate | Zero external npm dependencies. Standard library only (node:http, node:test, node:assert). Eliminates supply chain attack surface. |
</threat_model>
