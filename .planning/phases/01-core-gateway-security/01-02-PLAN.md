## Trust Boundaries

| Client Payload -> Gateway Memory Buffer | HTTP client transmitting request bodies to POST endpoints |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-04 | Tampering / CSRF | src/middleware/cors.js | mitigate | Restrict CORS origin reflection to explicit whitelist regexes (/^tauri:\/\/localhost$/, /^http:\/\/localhost(:\d+)?$/, /^http:\/\/127\.0\.0\.1(:\d+)?$/). Untrusted web origins receive no CORS allowance per CORE-03. |
| T-01-05 | Denial of Service | src/middleware/body.js | mitigate | Enforce strict 10MB (10,485,760 bytes) accumulation ceiling during stream consumption. Immediately destroy request stream and return HTTP 413 with ERR_PAYLOAD_TOO_LARGE if threshold is breached per CORE-05. |
| T-01-06 | Tampering / Input Injection | src/middleware/body.js | mitigate | Parse incoming JSON within try/catch. Catch SyntaxError and wrap into AppError with status 400 and code ERR_INVALID_JSON per CORE-05. |
| T-01-SC | Tampering | package.json | mitigate | Zero external npm dependencies. Standard library only (node:http, node:stream/consumers, node:test, node:assert). |
</threat_model>
